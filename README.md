# Python Game AI Vision Bot

Небольшая 2D-игра на Python и Pygame: игрок управляет космическим кораблём, уклоняется от астероидов и может стрелять по ним. В проекте также реализован режим управления кораблём нейросетевым агентом.

## Возможности

- ручное управление кораблём;
- генерация астероидов и обработка столкновений;
- стрельба и подсчёт очков;
- таблица рекордов для игрока и ИИ;
- режим ИИ с нейросетью прямого распространения;
- сенсорное представление игровой обстановки на основе лучей, направленных в сторону игрового поля;
- загрузка и сохранение параметров лучшей найденной нейросети через `best_brain.pkl`.

Согласно конфигурации проекта, агент получает 11 значений от сенсорных лучей, использует сеть с одним скрытым слоем из 6 нейронов и формирует 3 управляющих сигнала.

## Структура проекта

| Файл / папка | Назначение |
|---|---|
| `main.py` | Игровой цикл, отрисовка, управление, логика игрока и ИИ |
| `asteroid.py` | Создание, движение и столкновения астероидов |
| `bullet.py` | Логика снарядов |
| `data.py` | Настройки окна, изображения, игровые параметры и общие данные |
| `network.py` | Реализация нейросети, прямого прохода, мутации и сохранения модели |
| `best_brain.pkl` | Сохранённые параметры нейросети |
| `leaderboard.txt` | Рекорды |
| `assets/`, `img/` | Графические ресурсы |

## Требования

- Python 3
- Pygame

Установка Pygame:

```bash
python -m pip install pygame
```

## Запуск

Запускайте игру из корневой папки проекта, чтобы относительные пути к ресурсам и файлам данных разрешались корректно:

```bash
python main.py
```

## Управление

- `A` — движение влево;
- `D` — движение вправо;
- `Space` — стрельба;
- `Esc` — пауза;
- `1` — выбор режима бота на экране выбора режима;
- `2` — выбор ручного управления;
- `Enter` — переход к выбору режима после окончания игры.

## Как устроен режим ИИ

В `network.py` реализована простая полносвязная сеть с пороговой активацией. В `main.py` расстояния до препятствий, измеренные лучами, преобразуются в входной вектор сети. Выходы сети интерпретируются как управляющие действия. Функция `mutate` создаёт варианты сети, изменяя веса и смещения; состояние лучшей сети сохраняется в `best_brain.pkl`.

## Примечания

- В репозитории не обнаружен файл `requirements.txt`; для запуска явно подтверждена зависимость от Pygame.
- Файл `best_brain.pkl` и игровые ресурсы должны оставаться доступными по ожидаемым относительным путям.
- Описание подготовлено по исходному коду и структуре репозитория; отдельный запуск и тестирование игры не выполнялись.
